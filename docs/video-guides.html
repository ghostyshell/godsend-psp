Getting started

See your PSP and what is on it.

The Console

Plug the PSP in over USB and the Console tab shows the memory stick: free space, games and homebrew, disc images, save folders and library size, plus rescan, open, eject and environment checks.

  1. Connect the PSP in USB mode
  2. Read the stick summary
  3. Use Rescan, Open Stick, Eject Safely or Run Checks
  4. Watch the queue on the right

Library

Everything installed on the stick next to what you keep on your computer. Copy a game back to your computer, or open its info.

  1. Open Library
  2. Compare PSP and Local lists
  3. Press To Local to copy a game to your computer

Getting games

Find, download and move games.

Store

Search PSP games through the Game Debrid index or Internet Archive. Links are resolved through Real-Debrid or TorBox, then downloaded with aria2c.

  1. Pick Game Debrid or Internet Archive
  2. Search by title
  3. Open Links, or press Download

Downloads

Finished downloads wait here. Change the download folder or send a file to the memory stick with To PSP.

  1. Open Downloads
  2. Change the folder if you like
  3. Press To PSP

Files

A two-pane file manager: your computer on one side and the memory stick on the other, with folders, up and delete.

  1. Open Files
  2. Browse both sides
  3. Make folders or delete

Homebrew and media

Put software, music, video and disc images on the stick.

Homebrew

Browse emulators and custom firmware and install in one click, or import your own zip.

  1. Filter All, Emulators or CFW
  2. Press Install
  3. Or Import Zip

Music

Convert tracks to MP3 or M4A, or copy as-is, and push them to the stick.

  1. Choose a format
  2. Press Push Music

Video

Convert movies to the PSP AVC profile, generate .THM thumbnails and push them to the stick.

  1. Choose Convert to PSP AVC or Copy as-is
  2. Generate thumbnails
  3. Press Push Videos

Disc images

Import ISO or CSO images and convert between them, optionally compressing to CSO on import.

  1. Press Import Image
  2. Use To CSO or To ISO

Saves, mods and settings

Back up, customize and configure.

Save data

Back up every save folder or only the ones you pick, and restore from a backup zip.

  1. Press Backup All or select some
  2. Restore Zip to bring them back

Mods

Manage plugins, themes and custom firmware. seplugins are grouped by environment (Game, VSH, Pops); add a .prx, switch it on or off, or remove it.

  1. Open Mods
  2. Pick Game, VSH or Pops
  3. Add .prx, toggle or Remove

Settings

Add Real-Debrid or TorBox keys for the Store, choose store sources, set the downloads folder and the default music and video conversion.

  1. Add debrid accounts
  2. Choose store sources
  3. Set transfer defaults
