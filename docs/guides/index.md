# Guides

Practical walkthroughs for GODsend PSP. Start with the first one; the rest
can be read in any order.

1. [Connect your PSP](connect-your-psp.md) - USB mode, device detection,
   ejecting safely.
2. [Homebrew and custom firmware](homebrew-and-cfw.md) - the catalog,
   installing ARK-4, importing any zip, plugins.
3. [Music and video](music-and-video.md) - pushes, conversion presets,
   thumbnails.
4. [Disc images](disc-images.md) - ISO/CSO, compression, UMD metadata.
5. [Saves and mods](saves-and-mods.md) - backup/restore, themes, plugin
   toggles.
6. [Troubleshooting](troubleshooting.md) - common errors and fixes.
7. [Build from source](build-from-source.md) - toolchain, mock mode, CLI.

The headless CLI shares everything above; see the README for a command
tour.
